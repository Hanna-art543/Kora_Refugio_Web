# Kora Refugio Web 💜

## Descripción del Proyecto
Kora Refugio Web es una plataforma digital diseñada como un espacio seguro y educativo para adolescentes, cuyo propósito central es brindar apoyo, consejos y herramientas prácticas para el bienestar emocional y la gestión de sentimientos. Este proyecto académico implementa una arquitectura web integral que permite a los usuarios navegar por contenidos informativos, registrar sus vivencias y enviar consultas a través de formularios, mientras que el sistema garantiza la persistencia de los datos y ofrece un panel de administración para la gestión eficiente de la retroalimentación recibida.

---

## Tecnologías y Lenguajes Utilizados
Para el desarrollo de esta aplicación se utilizó un conjunto de tecnologías que cubren tanto el diseño visual como la lógica del servidor:

* **HTML (HyperText Markup Language):** Es la columna vertebral del proyecto; se utilizó para definir la estructura y el contenido de las 5 páginas web, organizando los textos, imágenes y formularios.
* **CSS (Cascading Style Sheets):** Se encargó de toda la capa estética. Gracias a CSS, el sitio tiene un diseño atractivo, colores coherentes y una disposición visual que facilita la lectura para los adolescentes.
* **JavaScript (JS):** Aporta dinamismo y comportamiento al lado del cliente. Se utilizó para validar formularios y crear elementos interactivos que mejoran la experiencia del usuario sin recargar la página.
* **Python (PY):** Es el lenguaje de programación principal para el backend. Se encarga de procesar la lógica de la aplicación, como la validación de usuarios y la comunicación con la base de datos.
* **Flask:** Es el micro-framework de Python que actúa como puente. Se utilizó para gestionar las rutas (URLs) y permitir que el código Python se comunique con los archivos HTML (usando el motor de plantillas Jinja2).
* **MySQL (SQL):** Es el sistema de gestión de bases de datos relacionales donde se almacena de forma estructurada toda la información de los registros, mensajes y el diario de los usuarios.
* **JSON (JavaScript Object Notation):** Se utilizó como formato ligero para el intercambio de datos, facilitando que la aplicación envíe o reciba información de manera estructurada y legible.

---

## Características Principales
* **Interfaz Intuitiva:** Página principal de bienvenida diseñada para la comodidad del usuario.
* **Navegación Fluida:** Sistema de 5 páginas web interconectadas.
* **Gestión de Mensajes:** Formulario de contacto funcional para el envío de información.
* **Panel Administrativo:** Sección protegida para visualizar y gestionar los mensajes recibidos.
* **Código de Calidad:** Repositorio organizado con código comentado para facilitar su mantenimiento.
